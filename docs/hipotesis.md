# Hipótesis iniciales

## H1: hashtag de marca
Un hashtag de marca consistente (#HormigasAI) mejora el reconocimiento y la
agrupación de publicaciones, pero no necesariamente el alcance.

## H2: texto superpuesto
Mostrar el nombre o hashtag de marca en el video mejora el recuerdo de marca.
Variantes: sin texto / 3-5 s / todo el video.

## H3: publicación multicanal
Adaptar la pieza a cada plataforma rinde más que subir el mismo archivo.
