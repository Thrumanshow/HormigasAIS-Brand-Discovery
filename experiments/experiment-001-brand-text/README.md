# EXP001 — H2: Overlay Text

## Estado

Activo / en preparación y publicación.

## Objetivo

Observar si la duración del texto de marca superpuesto durante la edición modifica las métricas observables de descubrimiento, retención, interacción y conversión del mismo contenido base.

## Hipótesis

**H2 — Overlay Text**

La duración de un texto de marca superpuesto puede asociarse con diferencias observables en el comportamiento del contenido publicado.

## Variable independiente

`brand_text_duration`

La variable experimental es exclusivamente la duración del texto de marca superpuesto en pantalla.

## Diseño

Experimento controlado de una variable.

### Variante A — Control

**Duración del overlay: 0 s**

No añade:

- texto de marca;
- hashtag gráfico;
- sticker;
- watermark;
- logo promocional.

Conserva únicamente los elementos originales del vídeo.

### Variante B

**Duración del overlay: 3–5 s**

Añade el mismo texto de marca definido para EXP001 durante una ventana de 3–5 segundos.

### Variante C

**Duración del overlay: vídeo completo**

Añade el mismo texto de marca definido para EXP001 durante toda la duración del vídeo.

## Elementos originales

El prompt original de la terminal contiene:

`A16@Soberano:~/HormigasAIS-Brand-Discovery`

y muestra:

`HormigasAIS`

Este elemento pertenece al contenido original y no constituye la intervención experimental.

## Constantes experimentales

Las variantes deben mantener constantes, en lo posible:

- tema;
- duración total del vídeo;
- audio;
- primer fotograma;
- caption;
- hashtags de publicación;
- cuenta;
- horario de publicación.

La única variable experimental debe ser `brand_text_duration`.

## Plataformas

- YouTube
- Instagram

## Puntos de medición

- 1 h
- 24 h
- 72 h
- 7 d

## Métricas

Se registrarán las métricas disponibles en cada plataforma.

Métricas prioritarias:

1. `non_follower_reach`
2. `profile_visits`
3. `new_followers`

También podrán registrarse:

- views;
- likes;
- comments;
- shares;
- saves;
- retention.

## Repetición

Una sola publicación por variante constituye únicamente una ronda exploratoria.

Cada variante debe repetirse 3–5 veces, rotando el orden de publicación cuando sea posible, antes de establecer conclusiones.

## Regla de interpretación

Los resultados representan observaciones del comportamiento del contenido.

Una diferencia numérica entre variantes no demuestra por sí misma causalidad ni garantiza una respuesta determinada del algoritmo de una plataforma.

## Regla de integridad

Los valores desconocidos deben registrarse como `unknown` o permanecer pendientes según el esquema correspondiente.

No se deben inventar:

- métricas;
- fechas;
- horas;
- URLs;
- duraciones;
- resultados.

Las mediciones realizadas no deben modificarse retrospectivamente sin documentar la corrección.
