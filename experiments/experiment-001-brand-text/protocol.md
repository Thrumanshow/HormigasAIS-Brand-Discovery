# EXP001 — Protocolo

## 1. Principio

Utilizar el mismo contenido base y modificar únicamente la variable experimental definida.

## 2. Variante A — Control

La edición no añade:

- texto de marca;
- logo;
- sticker;
- watermark;
- hashtag gráfico;
- texto promocional.

## 3. Elementos originales

El prompt original de la terminal puede mostrar:

`HormigasAIS`

Esto debe registrarse como:

`original_brand_visible: true`

No debe registrarse como texto de marca añadido experimentalmente.

## 4. Datos de publicación

Para cada publicación registrar:

- plataforma;
- variante;
- URL;
- fecha;
- hora;
- duración;
- caption;
- hashtags.

## 5. Mediciones

Registrar métricas en:

- 1 h;
- 24 h;
- 72 h;
- 7 d.

## 6. Integridad

No modificar retrospectivamente una medición.

Si existe un error de registro, conservar el dato original y documentar la corrección en las notas.

## 7. Interpretación

El experimento describe diferencias observadas.

No debe atribuir causalidad a una diferencia sin evidencia adicional.
